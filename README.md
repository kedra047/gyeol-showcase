# 결 — AI 이야기 서비스

사용자가 세계와 배역을 선택하고 AI와 이야기를 이어가는 웹 서비스입니다. 이 저장소는 프로젝트의 구조와 주요 결정을 설명하는 소개 자료입니다. 서비스 전체 소스와 사용자 데이터는 포함하지 않습니다.

현재는 초대받은 사용자에게 제공하는 시험 서비스입니다. 상용 운영 실적이나 대규모 실제 LLM 품질 검증을 주장하지 않습니다.

## 프로젝트에서 맡은 역할

제품 방향과 우선순위, 완료 기준, 결과를 받아들일지 여부는 제가 결정했습니다. 실제 화면을 사용하며 사용자 경험의 수정 사항을 판단하고, Codex와 Claude를 활용해 코드 구현, 문서화, 검토와 시험을 진행했습니다. AI가 작성한 결과도 구현과 기록에 맞춰 다시 검토했습니다.

## 주요 기능

- 세계와 배역을 만들고, 게시된 세계를 개인 사본으로 설치합니다.
- 개인 사본의 버전을 관리하고 원본 업데이트를 선택해 적용합니다.
- 대화에서 답변 후보를 비교하고, 메시지 편집으로 이야기 분기를 만듭니다.
- 생성 결과에 사용 토큰을 표시하고 잉크 사용 내역을 제공합니다.
- 초대 전용 로그인, 운영자 패스키 인증, 계정 자료 내보내기와 삭제 대기를 지원합니다.
- 백업과 복원 기능을 별도 시험 환경에서 검증했습니다.

## 자료

- [서비스 구조](architecture.md)
- [주요 결정과 검증 범위](decisions.md)

서비스는 TypeScript, React 19, Next.js 호환 App Router를 제공하는 vinext, Cloudflare Workers·D1·R2와 외부 LLM API를 사용합니다. 실제 LLM의 응답 시간과 서비스 내부 처리 시간은 구분해 다루며, 지금까지의 부하 측정은 모의 모델을 사용한 내부 처리 시험입니다.

## 현재의 한계

결제 연결은 보류 상태입니다. 부하 시험은 모의 모델을 사용했으며 실제 LLM의 응답 품질이나 외부 공급자 처리 용량을 입증하지 않습니다. 백업·복원 시험은 제한된 시험 자료를 대상으로 진행했습니다. 예약 작업은 현재 중지되어 있습니다.
